# SHARE Service360

SHARE Ambassador programme platform for engagement, training, feedback, programme administration, service performance and reporting.

- Personal GitHub Pages: frontend demonstration only.
- Corporate EKS DEV: frontend and Node API may be deployed as one container using the root Dockerfile.
- PostgreSQL 16 schema: backend/sql/001_identity.sql
- Corporate deployment notes: CORPORATE-DEV-DEPLOYMENT.md

**Status:** Work-in-progress DEV/UAT code, not production-ready. The existing frontend still includes demo/local data outside the new identity and Ambassador administration API. Full workflow persistence and regression testing remain pending.

No AI agents or AI pipelines are part of this application.
